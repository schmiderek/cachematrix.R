# T7 Ride Check

A daily pre-ride checklist for the Yamaha Ténéré 700, built as one web page (`index.html`).

- Follows the T-CLOCS order: Tires, Controls, Lights, Oil, Chassis, Stands, plus rider kit.
- Tap **OK**, **Fix** or **N/A** on each item. Fix opens a note box.
- Enter tire pressures, chain slack and odometer.
- Tap **Save to Google Drive**. On Android this opens the share menu; pick **Drive** and the check is saved as a text file.
- Your progress is kept on the phone if you close the page. Past checks are listed at the bottom.

## Put it on your phone

1. On GitHub, open this repository's **Settings → Pages**.
2. Under **Source** choose **Deploy from a branch**, pick the branch that has `index.html`, folder `/ (root)`, and save.
3. After a minute GitHub shows the web address. Open it in Chrome on your phone.
4. In Chrome's menu tap **Add to Home screen** so it opens like an app.
